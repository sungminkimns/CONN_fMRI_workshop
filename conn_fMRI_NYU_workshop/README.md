# Resting-State fMRI Analysis Using CONN Toolbox
**DataSet**: NYU CSC TestRetest

**Software**: CONNToolbox | SPM | MATLAB
## Project Overview
The analyses were completed as assignments with a CONN Toolbox workshop held from Sep 10 to Oct 12, 2026, using the publicly avialable NYUVSV TestRestest dataset. 

The dataset includes 25 participants, each with three scanning sessions.

Data Source: https://www.nitrc.org/projects/nyu_trt/.

Detailed analysis methods are documented in methods.md
